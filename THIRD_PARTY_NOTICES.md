# Third-party notices

## Card illustrations

Pamela Colman Smith illustrated A. E. Waite’s *The Pictorial Key to the Tarot*
(1910). The app uses public-domain snapshots of those original illustrations.
[Artwork provenance](reference/art/README.md) records the distribution source
and acquisition date. `reference/sources.json` records all 78 image hashes.
The application’s MIT License does not claim authorship of these images.

## Meanings and descriptions

Historical meanings and descriptions are by A. E. Waite. The JSON packet was
adapted from [ekelen/tarot-api](https://github.com/ekelen/tarot-api/tree/1a3cf8e17f036aeeb5d32fd6050deef5cced1662),
whose package metadata declares ISC and whose README permits JSON reuse.
No upstream API implementation is included. The app uses a bundled snapshot;
it does not contact that service. `reference/cards.json` contains that snapshot.
